# IC-JIS Layouts

This directory contains reference layouts and layout variations based on the IC-JIS design principles.

## IC-JIS Is Not Necessarily One Fixed Layout

IC-JIS should not be understood simply as a single fixed keyboard arrangement.

The project explores a set of design principles that can potentially be applied to different keyboard forms while preserving the core idea.

Possible variations may include:

- conventional JIS-style keyboards,
- HHKB-style compact keyboards,
- 40% keyboards,
- split-spacebar keyboards,
- and other programmable layouts.
