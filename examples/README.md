# IC-JIS Examples

This directory contains experimental implementations of IC-JIS concepts.

## Purpose

IC-JIS can be evaluated without immediately designing or manufacturing new keyboard hardware.

Existing programmable keyboards provide a practical environment for testing many of the ideas proposed by IC-JIS.

The purpose of this directory is therefore simple:

> Try the concept before changing the hardware.

## What Can Be Tested?

Experiments may include:

- thumb-accessible keys around the spacebar,
- Japanese input switching,
- Mod-Tap assignments,
- layer-based functions,
- split-spacebar configurations,
- compact keyboard adaptations,
- and combinations of these techniques.
