# IC-JIS Visual References

This directory contains visual materials used to explain the IC-JIS concept.

## Structure

### `concept/`

Diagrams and illustrations explaining IC-JIS itself, including:

- reference keyboard layouts,
- spacebar-area designs,
- Japanese input key arrangements,
- comparisons between layout approaches,
- and conceptual implementation diagrams.

### `historical/`

Visual references related to historical Japanese keyboard implementations and other designs examined during the development of IC-JIS.

These materials help explain how particular physical key arrangements developed and how they relate to the IC-JIS proposal.

## Use in Project Documentation

Selected images from this directory may be referenced from the main README and technical documents where they help explain the project.
